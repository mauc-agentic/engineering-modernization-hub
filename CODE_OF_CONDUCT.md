# Código de conducta

Este proyecto adopta el [Contributor Covenant v2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/)
como su código de conducta. En resumen: sé respetuoso, acepta la crítica constructiva con
buena fe y no toleres el acoso ni la discriminación de ningún tipo.

Para reportar una conducta inaceptable, usa el reporte privado de GitHub del repositorio
(pestaña *Security* → *Report a vulnerability*) e indícalo en el asunto.
